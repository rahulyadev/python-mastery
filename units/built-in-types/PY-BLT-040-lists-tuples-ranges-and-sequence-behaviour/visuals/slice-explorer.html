      How to read this visual, key insight, and limits

      Read: source cells stay in source order. Highlighted cells show their visit number; the second row follows that visit order. Negative indices label the same source positions.

      Insight: the sign of the step sets direction and defaults. With a negative step, an omitted stop reaches past position zero; explicit -1 instead refers to the last position.

      Limit: this is an offline model for ordinary list slices, not a Python interpreter. Length is bounded to 0–12 and bounds to JavaScript safe integers. It does not model nested sharing, custom objects, or memory layout. Wrapping source cells on small screens does not change their indices.

      Normalized bounds describe range(start, stop, step) positions. Do not reuse them as a raw slice: Python would normalize negative numbers again.
