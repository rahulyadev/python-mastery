How to read this visual

Choose a scenario and move one operation at a time. Each state shows the result after that operation. Visit numbers indicate iteration positions, not keys for numeric indexing. Matching list labels indicate the same child object.

Key insight: views follow the original dictionary; shallow copies keep independent bindings but can still share children.

Limitation: these are eleven captured states from real Python, not a Python interpreter or a drawing of CPython memory. The page has no network dependencies. Refresh or check the data with trace_data.py.
